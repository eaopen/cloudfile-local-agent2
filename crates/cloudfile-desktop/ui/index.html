如何开始本地编辑？

在 CloudFile 网页选择文件，点击“本地编辑”。文件打开后，回到本机应用继续工作。

本地打开

普通编辑

在本机应用保存后，回到任务中心点「立即上传」才会写入云端；不做自动回传。

独占编辑

编辑完成后，在任务中选择“提交版本”或“签入并释放”（开发中）。

遇到冲突或提交结果待确认，请在任务列表处理。本地文件会保留。单文件上限 128 MiB。

首次安装与连接检查

此页只协助检查本机组件是否就位。服务地址已内置，无需配置。

    在 Chrome 里加载这个扩展

    扩展包已经下载并解压到本机，位置见下面的目录。浏览器不允许程序代劳这一步，需要你在 Chrome 里手动加载一次。

    1. 打开 Chrome，在地址栏输入 chrome://extensions 后回车（浏览器不再允许从外部直接弹出这一页，需要手动输入或粘贴）。
    2. 打开页面右上角的「开发者模式」。
    3. 点左上角「加载已解压的扩展程序」，在弹窗的地址栏粘贴下面这个目录，回车后点「选择文件夹」。
    4. 回到这里点「完成」；扩展列表里出现 CloudFile 即装好。
